# 🏎️ BumberCar - FiveM 범퍼카 게임모드

FiveM용 범퍼카 게임모드입니다. 다양한 게임 모드와 아이템을 사용하여 마지막까지 살아남으세요!

## ✨ 주요 기능

### 🎮 게임 모드
- **아이템전 (개인전/팀전)** - 아이템을 사용하여 상대를 격파
- **노아이템전 (개인전/팀전)** - 순수한 실력으로 승부
- **폭탄 건내기 (개인전/팀전)** - 폭탄을 다른 플레이어에게 넘기세요
- **보스 모드** - 한 명의 보스 vs 나머지 플레이어

### 🎯 핵심 시스템
1. **로비 시스템**
   - 맵 선택
   - 게임 모드 선택
   - 준비 완료/해제
   - 관전 모드 선택
   - 자동 시작 타이머

2. **차량 데미지 시스템**
   - 속도 기반 데미지 계산
   - 차량별 고유 스탯 (체력, 공격력, 방어력)
   - 충돌 쿨다운
   - 스폰 시 무적 시간

3. **아이템 시스템**
   - **즉발형 아이템**: 수리, 차량 변경
   - **사용형 아이템**: 공격력 증가, 방어력 증가, 속도 증가, 부스트, 점프, 정지, 폭발
   - 아이템 슬롯 (2개)
   - 게임 모드별 아이템 제한

4. **라운드 시스템**
   - 대기 → 준비 → 진행 → 종료
   - 라운드 타이머
   - 자동 시작
   - 결과 화면

5. **경계 시스템**
   - 원형/사각형 경계 지원
   - 경계 이탈 시 경고 타이머
   - 시각적 경계선 표시
   - 물에 떨어지면 즉시 사망

6. **관전 시스템**
   - 로비에서 관전자 선택 가능
   - 좌클릭/우클릭으로 플레이어 전환
   - 관전 대상의 차량 정보 표시

7. **NUI 프론트엔드**
   - 로비 UI
   - 게임 HUD (차량 스탯, 아이템 슬롯, 효과 목록)
   - 관전 UI
   - 경계 타이머 UI
   - 폭탄 타이머 UI
   - 결과 화면
   - 3D2D 텍스트 (플레이어 이름, 아이템 이름)

## 📦 설치 방법

1. 이 리소스를 FiveM 서버의 `resources` 폴더에 넣습니다
2. `server.cfg`에 다음을 추가합니다:
```cfg
ensure bumbercar
```

3. 서버를 재시작합니다

## 🎮 사용 방법

### 플레이어
- `/bumpercar` - 로비 열기
- `G` - 아이템 슬롯 1 사용
- `H` - 아이템 슬롯 2 사용
- `좌클릭` - 관전 시 이전 플레이어
- `우클릭` - 관전 시 다음 플레이어

### 관리자
- `/bcstart` - 게임 강제 시작
- `/bcend` - 게임 강제 종료
- `/bcedit` - 맵 편집 모드 (개발 예정)
- `/bcmode <모드>` - 게임 모드 강제 설정
- `/bcdebug` - 디버그 정보 출력

## ⚙️ 설정

### 기본 설정 (`config/config.lua`)
```lua
Config.Lobby.MinPlayers = 2              -- 최소 플레이어 수
Config.Round.RoundTime = 300             -- 라운드 시간 (초)
Config.Vehicle.DefaultHealth = 1000      -- 기본 차량 체력
Config.Boundary.WarningTime = 5          -- 경계 이탈 경고 시간
```

### 차량 추가 (`config/vehicles.lua`)
```lua
{
    model = 'blista',
    name = '블리스타',
    health = 800,
    defense = 80,
    damage = 40,
    speed = 1.0
}
```

### 맵 추가 (`config/maps.lua`)
```lua
your_map = {
    name = '맵 이름',
    description = '맵 설명',
    icon = '🏖️',
    boundary = {
        type = Constants.BoundaryType.CIRCLE,
        center = vector3(x, y, z),
        radius = 150.0
    },
    spawnPoints = {
        vector4(x, y, z, heading),
        -- ...
    },
    itemSpawns = {
        vector3(x, y, z),
        -- ...
    }
}
```

### 아이템 추가 (`config/items.lua`)
```lua
your_item = {
    name = '아이템 이름',
    type = Constants.ItemType.USABLE,
    effect = Constants.ItemEffect.SPEED_BOOST,
    icon = '⚡',
    color = '#FFFF00',
    description = '아이템 설명',
    duration = 10,
    multiplier = 1.5
}
```

## 🗺️ 기본 맵

1. **비치 아레나** 🏖️ - 해변가에 위치한 넓은 아레나
2. **도심 주차장** 🏙️ - 빌딩 숲 사이의 옥상 주차장
3. **경기장** 🏟️ - 거대한 원형 경기장
4. **공항 활주로** ✈️ - 넓고 긴 공항 활주로
5. **산악 도로** ⛰️ - 구불구불한 산악 도로

## 🎨 커스터마이징

### UI 색상 변경
`html/css/style.css` 파일에서 색상을 변경할 수 있습니다.

### 사운드 변경
`config/config.lua`의 `Config.Sounds` 섹션에서 사운드를 변경할 수 있습니다.

## 🐛 알려진 이슈

- 일부 차량은 충돌 데미지가 제대로 계산되지 않을 수 있습니다
- 네트워크 지연이 심한 경우 차량 동기화 문제가 발생할 수 있습니다
